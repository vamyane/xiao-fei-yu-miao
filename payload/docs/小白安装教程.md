# 小肥鱼喵 · 小白安装教程（从零开始）

> 目标：让你的 QQ 里出现一个会聊天、会发表情包、会画图、会发语音的 AI 好友「小肥鱼喵」。
> 你只需要准备 3 样东西：**一台 Windows 电脑、一个 QQ 小号、一个 DeepSeek API Key**。

---

## 第 0 步：准备清单

| 需要 | 说明 |
| --- | --- |
| Windows 10/11（64 位） | 至少 10GB 空闲磁盘（装画图功能要 20GB） |
| QQ 小号 | 专门给机器人用。**强烈建议用小号**，不要用主号 |
| DeepSeek API Key | 打开 https://platform.deepseek.com → 充值 → API Keys → 创建，复制 `sk-` 开头的密钥 |
| 网络 | 能正常上网即可（安装器会自动走国内镜像下载） |

---

## 第 1 步：安装 DSH（机器人的「大脑」）

1. 打开官方地址下载 Windows 桌面版：**https://deepseek-harness.github.io/**
2. 按默认设置安装，打开 DSH。
3. 首次启动按提示完成初始化（登录 / 填写 API Key 都可以，后面还能改）。
4. **先不要关 DSH**，它要一直运行（可以最小化到托盘）。

> DSH 是闭源商业软件，本安装包不包含它，必须由你从官方安装并同意其协议。

---

## 第 2 步：安装 SnowLuma（QQ 网关）

> SnowLuma 的许可协议禁止第三方打包分发，所以这一步需要你手动装（只有 3 分钟）。

1. 打开 https://github.com/SnowLuma/SnowLuma/releases/latest
2. 下载 **`SnowLuma-v*-win-x64.zip`**（完整版，文件名带 win-x64、不带 lite）。
3. 解压到 `D:\SnowLuma`（或别的位置，安装器里可以改）。
4. 双击 `D:\SnowLuma\launcher.bat` 启动。
5. 浏览器打开 **http://127.0.0.1:5099**
   - 初始账号 `admin`，初始密码在启动窗口/日志里（`initial credentials: ...`）
   - 同意 EULA / 隐私协议 → 修改密码（记住它）
   - 点「接入 QQ」→ 用**小号手机 QQ** 扫码登录
   - 左侧「网络 / OneBot」：开启 **WebSocket 服务端（端口 3001）** 和 **HTTP API（端口 3000）**，accessToken 留空
6. 保持 SnowLuma 运行。

---

## 第 3 步：一键部署

1. 解压「小肥鱼喵一键部署包.zip」到任意目录（不要在压缩包里直接运行）。
2. 双击 **`小肥鱼喵一键部署.exe`**。
3. 界面里填写：
   - 勾选顶部风险与协议说明
   - DeepSeek API Key（部署完成后会自动复制到剪贴板）
   - 你的**主号 QQ**（用来和机器人聊天）
   - 机器人小号 QQ（可留空，扫码后自动识别）
   - 安装目录（默认 `D:\qq-bridge`）
   - SnowLuma 目录（默认 `D:\SnowLuma`）
   - 勾选「DSH 已安装并完成初始化」「SnowLuma 已启动并扫码登录」
   - 可选：勾选安装 ComfyUI 画图（约 4GB 下载，也可以以后再装）
4. 点 **「▶ 开始部署」**，等进度跑完（首次约 5~15 分钟，取决于网速）。
5. 看到「✅ 部署完成，小肥鱼喵已上线」就成功了。

---

## 第 4 步：把 API Key 填进 DSH

安装器会把你刚才输入的 API Key **自动复制到剪贴板**：

1. 打开 DSH → 设置 / 模型配置
2. 把 Key 粘贴进去，选择模型 `deepseek-flash`
3. 保存

> 之后机器人就用这个 Key 调用 DeepSeek。

---

## 第 5 步：验收

1. 双击桌面 **「小肥鱼喵」**，应该看到「已上线」。
2. 用你的主号 QQ 给小号发一句「在吗」。
3. 等几秒收到回复 → 成功！
4. 把机器人小号拉进一个群，@它说话即可群聊。

---

## 常见问题

**Q：启动后 App 显示未上线？**
A：在 App 里点「启动全部」，等 1~2 分钟；仍不行就看下方日志，或把 `docs\给AI的安装指令.md` 发给你的 DSH Agent，让它自动排查。

**Q：没有收到 QQ 回复？**
A：检查 ① DSH 是否开着 ② SnowLuma 是否在线（5099） ③ 主号 QQ 是否填对（白名单）。

**Q：会不会封号？**
A：SnowLuma 属于第三方协议端，腾讯可能风控。**务必用小号**，不要群发广告、不要高频打扰陌生人。

**Q：画图/语音不工作？**
A：画图需要 ComfyUI（安装器可选装）；语音默认用 Edge TTS（免费在线，需要联网）。

**Q：想彻底卸载？**
A：停止服务后删除安装目录即可；另外删除 `%USERPROFILE%\.dsh\profiles\<profile>\cordis.patch.yml` 里含 `mcp-media` 的段落，以及计划任务 `QQBotStart`/`QQBotStop`。

## 目录说明

```
D:\qq-bridge\            ← 安装目录
  app\小肥鱼喵.exe        ← 控制台 App
  src\                   ← 桥接与媒体工具
  config.json            ← 机器人配置（频率、音色、白名单…）
  start-all.ps1          ← 一键启动脚本
  docs\                  ← 本教程 + 给 AI 的指令
  state\                 ← 运行数据与日志
```
